### Highlights

- Built on [DuckDB v2.0.0](https://github.com/duckdb/duckdb/releases/tag/v2.0.0). httpfs, Avro, Iceberg, Quack, DuckLake, and Spatial are pinned to the exact commits DuckDB v2.0.0 builds them with.
- Built with Emscripten 6.0.13 (up from 4.0.22), which also trims about 0.8 MiB from each Workers WASM.
- Exception handling now works inside the bundled extensions. Their `catch` blocks were compiled out before, so recoverable errors escaped as failures: a missing remote file during Iceberg metadata discovery surfaced as an HTTP 404, and a non-numeric `Content-Length` failed the query.
- The browser WASM is smaller than in 1.5.6 (24.7 MiB, 7.1 MiB gzipped) through native Wasm exceptions, no C++ RTTI, and a reduced extension set.
- `ST_AsGeoJSON` and `ST_GeomFromGeoJSON` stay available in `@ducklings/workers-spatial`. DuckDB 2.0 moved them into the json extension, which the packages do not bundle.

### Breaking changes

- **`@ducklings/browser` no longer bundles Avro and Iceberg.** `read_avro`, `iceberg_scan`, `iceberg_metadata`, and `iceberg_snapshots` are unavailable in the browser; use [`@ducklings/workers-iceberg`](https://www.npmjs.com/package/@ducklings/workers-iceberg) on Cloudflare Workers. With both extensions, the browser WASM would exceed Cloudflare Pages' 25 MiB per-file limit.
- **`@ducklings/browser` requires WebAssembly exception handling:** Chrome 95+, Firefox 100+, or Safari 15.2+.
- **`INSTALL` and `LOAD` fail with a new message:** `Permission Error: Installing external extensions is not supported: this build does not link the loadable_extensions library` (and the `Loading` equivalent). Code matching the old "disabled through a compile time flag" text needs updating.
- **The Workers WASM files are about 30% larger**, because DuckDB 2.0's own code grew by about 35%. All Workers packages still fit Cloudflare's 64 MiB limit; recheck your Worker's `Total Upload` if it bundles other large assets.
- **DuckDB 2.0 changes SQL behavior** in places. Review the [DuckDB v2.0.0 release notes](https://github.com/duckdb/duckdb/releases/tag/v2.0.0) before upgrading.
